Meu Site
Este projeto é um site desenvolvido em HTML e CSS , com o objetivo de apresentar informações sobre mim e algumas fotos.

Estrutura do projeto
meu-site/
│
├── index.html          # Página inicial
├── sobremim.html       # Página sobre mim
├── contato.html        # Página de contato
├── Fotos.html          # Página com fotos
│
├── ffotos/             # Pasta com as fotos utilizadas no site
│
└── imag/               # Pasta com imagens utilizadas no site
Páginas
Início ( index.html) — Página principal do site.
Sobre Mim ( sobremim.html) — Apresenta informações sobre mim.
Contato ( contato.html) — Contém formas de entrar em contato.
Fotos ( Fotos.html) — Reúna as fotos utilizadas no projeto.
Às vezes preparado
HTML5
CSS3
Organização das imagens
As imagens utilizadas no site estão organizadas nas pastas ffotose imag, facilitando a organização dos arquivos do projeto.

Objetivo
O objetivo deste projeto é colocar em prática os conhecimentos aprendidos em HTML e CSS , criando um site organizado, funcional e com navegação entre diferentes páginas.
